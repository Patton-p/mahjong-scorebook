# 血战账本 · 照片逐局版

五位玩家：日落尤…、轩逸、在西…、机器人、机器人2，可修改昵称、勾选机器人。支持截图本地OCR、照片逐局入账、手动记账、撤销、CSV导出和备份恢复。

## 一张照片一局

不读取图片中的游戏对局数，也不填写对局数。空白账本第一张照片核对入账为第1局，第二张为第2局，依次递增。识别与核对不增加局数，只有成功保存才增加1局。

上传图片后核对昵称、正负号和四行对应玩家，点击“确认对应关系 · 保存第N局”，确认后直接保存，无需再点保存。没有出现在截图中的第五位本局为0。每张照片的完整分数作为本局分数直接累加，不计算累计战绩差额。请上传单局结算图；如果上传好友房累计战绩图，仍按本照片分数直接累加，连续的累计图可能重复计分，请自行确认。

原来的8局演示与局数填写已移除。新开一场从第1局编号；撤销最近一局后编号回退。旧版历史和备份保留，旧累计差额记录会标注来源。

## 机器人不参与算分

默认两位机器人无论输赢均结算为0。只统计真人，W=赢分总额，L=输分绝对值总额，P=min(W,L)。赢家按P×个人赢分/W，输家按-P×个人输分绝对值/L分配；真人全部赢或全部输时全部为0。精确至0.01分，用最大余数法补齐尾差，确保真人合计为0。加权规则逐局应用，原始逐局记录不改写。

## OCR与数据

截图在浏览器中识别，不上传，不调用付费模型。首次需联网下载开源OCR核心和语言数据。昵称特殊字符和不同版式可能需要手动修正。优先支持示例竖版好友房战绩图的四行识别，但按照片逐局入账。

GitHub Pages从jsDelivr下载Tesseract.js-core和@tesseract.js-data中英文资源，Tesseract.js 6.0.1、core 6.0.0，许可见vendor/ocr。记录保存在当前浏览器，换设备或网址前请备份，不要将个人备份上传公开仓库。

GitHub Settings → Pages → Deploy from a branch → main → / (root)。本地手动记账可打开index.html；OCR通过HTTP/HTTPS运行。

## 每张照片先加权，总分直接累加

每局保存时，单独计算并存储该照片的加权分（整数分位，显示保留两位小数），同时保存该局的机器人名单和开关状态。总分=第1局加权分+第2局加权分+……，不再将全部原分合并后重算。修改机器人设置仅影响后续新局，已保存的加权分不变。

例：第1局[38,9,-23,-24,0]，加权[18.60,4.40,-23.00,0,0]；第2局[-10,20,-40,15,15]，加权[-4,20,-16,0,0]；总分[14.60,24.40,-39.00,0,0]。

历史列表和CSV同时列出每局原始分与加权分；撤销只移除最后一局对应的加权分。旧版记录在加载或恢复时，按原始逐局分数和当时账本的机器人设置补算每局加权分，再逐局相加。备份同时保存每局加权结果。
