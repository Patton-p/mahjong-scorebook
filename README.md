# 血战账本

四川血战到底四人积分记账网页。支持累计战绩差额入账、单局记账、分数平衡检查、撤销、CSV 导出及 JSON 备份恢复。

## 开启网站

仓库 Settings → Pages → Build and deployment：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)
- 点击 Save，等待 Pages 部署完成后，通过页面显示的 Visit site 打开网站。

## 使用说明

可直接下载并打开 index.html，无需安装依赖。

本工具未连接欢乐麻将后台。上传好友房累计战绩截图后，会在当前浏览器中识别昵称、四人分数和局数，核对后填入表格；不会上传截图，也不调用付费模型。累计战绩截图按积分排名，请根据昵称对应玩家，切勿按名次对应。示例数据只是填表参考，需要确认后保存。

记录保存在当前浏览器中，不跨设备或网址同步。换网址前请点击“备份数据”，然后在新网址使用“恢复备份”。不要把个人备份提交到公开仓库。

## 机器人输分加权结算

在页面顶部选择机器人玩家，并勾选“机器人输分不计入结算”。当该机器人本场累计得分为负时，其结算分为 0，真人输家保持原分，真人赢家按原赢分比例分享真人输分总额。例：原分 [38,9,-23,-24]、最后一位为机器人，结算为 [18.60,4.40,-23.00,0.00]。

公式：真人赢家结算分 = 真人输分总额 × 该赢家原赢分 ÷ 真人赢家原赢分总额。精确到 0.01 分，按最大余数分配尾差，余数相同按玩家顺序，确保合计为 0。若真人无人输分，则真人赢家结算为 0；机器人赢分或持平时保留四人原分。

结算始终依据整场原始累计战绩计算，不逐局加权相加。原始记录不会改写，累计截图差额仍依据原始积分。关闭选项可恢复显示原始分数。CSV 包含原始记录、原始累计和调整后结算；备份包含机器人设置。换人或换机器人请新开一场。

## 截图自动识别

点击“上传结算截图 · 自动识别”，等待识别完成；核对昵称、正负号和对局数，并为每一行选择对应玩家，再点击“确认对应关系 · 填入记账表”。填入后仍需点击保存，系统不会直接自动入账。空白账本可按识别昵称建立四位玩家，须先修正昵称。

优先支持本项目示例的竖版“好友房战绩”完整截图；其他版式、裁剪图、模糊图片及特殊字体可能需人工修正。昵称或排名不能可靠匹配时，不按排名猜测玩家。四人分数合计不为0或玩家对应重复时，会阻止填入。

Tesseract.js 6.0.1、Tesseract.js-core 6.0.0，语言数据来自 @tesseract.js-data。GitHub Pages 首次识别会从 jsDelivr 下载开源 OCR 核心和中英文语言资源；需联网下载，之后语言数据可由浏览器缓存。下载资源不会上传截图；网络不可用、内存不足或浏览器不兼容时，可取消、重试或手动录入。保留上方机器人输分加权规则。
