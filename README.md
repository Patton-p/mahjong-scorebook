# 血战账本

四川血战到底五位玩家记账：日落尤…、轩逸、在西…、机器人、机器人2。支持修改昵称、机器人多选、截图本地识别、累计战绩差额入账、单局录入、撤销、CSV导出和备份恢复。

## 机器人不参与算分

默认将最后两位标记为机器人。勾选“机器人不参与算分（无论输赢）”后，所有机器人结算分始终为0。

只统计真人：W=原赢分总额，L=原输分绝对值总额，P=min(W,L)。真人赢家按 P×个人原赢分/W 分配；真人输家按 -P×个人原输分绝对值/L 分配。真人全部赢、全部输或全为0时，P=0，真人全部结算为0。结果精确到0.01分，最大余数法补齐尾差，同余数按玩家顺序，确保合计为0。原始战绩不改写。

例：[38,9,-23,-24,0]，后两位为机器人，结算为[18.60,4.40,-23.00,0,0]；[10,20,-60,15,15]结算为[10,20,-30,0,0]；机器人一赢一输也全部排除。

## 四人截图对应五位玩家

上传完整“好友房战绩”截图，在浏览器中识别四行昵称、得分和累计局数。按昵称选择对应的四位玩家，再确认填入。未出现在截图中的第五位按0分填入本次累计战绩。换参赛名单请新开一场，避免将不同好友房的累计战绩混在一起。

截图中名字可能有错字，排名也可能变化，请核对昵称、正负号、局数和玩家对应关系。五人表格和原始记录的分数需合计为0；识别或对应关系不完整时不允许填入。填入后仍需点击保存，不会自动记账。

截图不上传、不调用付费模型。GitHub Pages首次识别需从jsDelivr下载Tesseract.js-core和中英文语言资源。使用Tesseract.js 6.0.1、core 6.0.0和@tesseract.js-data；开源许可见vendor/ocr。支持取消、重试和手动修正，优先适配示例竖版截图。

## 数据与部署

旧四人数据和备份自动升级：补第五位机器人2，旧记录第五位为0，第二位昵称改为轩逸。旧机器人选项保留并增加第五位，默认启用新的全机器人剔除规则。备份恢复支持四人和五人格式。

记录只保存在当前浏览器，不跨设备或域名同步。换设备或网址前请备份；不要将个人备份提交到公开仓库。

可直接打开index.html进行手动记账；截图OCR需要通过HTTP/HTTPS访问。GitHub仓库Settings → Pages，Source选择Deploy from a branch，分支main，目录/ (root)。
